What it is

Not a news feed. It keeps memory across days and tracks themes over time, so the interesting part is not that something was published — it is that unrelated sources started pointing the same direction at once.

Duplicates are collapsed before anything is counted, so the same story arriving twice raises confidence without pretending to be two findings.
